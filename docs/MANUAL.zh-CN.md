# ENCO-02 使用手册

[English](MANUAL.md) | **简体中文**

ENCO-02 是一台桌面 AI 陪伴机器人。它有一块 240×320 屏幕上的动画角色脸、三轴电动头部和一只摄像头"眼睛"，通过小智云端助手用语音控制。借助 Mac 上的一个小型桥接程序，它还能控制家里的泳池和 SPA。

下面的功能**按酷炫程度排序**，最惊艳的在前。表中列出的说法都能被固件或助手识别。不必一字不差：云端模型能理解近义说法；最重要的几类指令在设备本地也做了匹配，所以即使模型只是聊天回复，指令也照样执行。

---

## 快速上手

1. **开机**：屏幕显示角色脸和状态栏。第一次开机请看 [Wi‑Fi 配网](#15-wi-fi-配网热点)。
2. **唤醒**：说 **"Hi 安可"**（"安可"、"Hi ENCO"、"你好"也可以），状态变为 **聆听中**。
3. **正常说话**：她会语音回答，字幕栏显示文字，表情随之变化。
4. **让她休息**：说 **"退下" / "去休息" / "待命"**，或 120 秒不说话。

## ★★★★★ 1. 会"活"的角色脸

屏幕上是手绘的 K3「优雅短发」角色，全彩，直接从闪存绘制。

| 行为 | 说明 |
|---|---|
| **眨眼** | 睁 → 半闭 → 闭 → 半闭 → 睁（约 240 毫秒），每 2.4–6 秒随机一次，不显机械 |
| **口型与下巴同步** | 嘴和下巴跟随扬声器的实际输出（而不是网络状态），出声时动、静音 200 毫秒内停 |
| **发丝微风** | 刘海和两侧发梢每 1.6–4.8 秒轻轻飘动 |
| **情绪反应** | 每条 AI 回复都带一种情绪（共 21 种）。她说完后，对应表情保持 2.5 秒 |
| **随机氛围表情** | 待机：每 10–25 秒出现一个平和表情，持续 2–3.6 秒。聆听中：每 2.4–5 秒出现一个专注表情，持续 1.6–2.4 秒 |

### 语音点播表情

| 说 | 表情 |
|---|---|
| "开心一点" / "笑一个" | 😊 **开心 happy** |
| "难过" / "伤心的表情" | 😢 **难过 sad** |
| "眨个眼" | 😉 **眨眼 wink** |
| "嘟嘴卖萌" / "卖个萌" | 😗 **嘟嘴 pout** |
| "惊讶" / "吓一跳" | 😮 **惊讶 surprised** |
| "做个生气的表情" | 😠 **生气 angry** |
| "害羞" | ☺️ **害羞 shy**（淡淡腮红） |
| "思考一下" / "想一想" | 🤔 **思考 thinking** |
| "恢复表情" / "正常一点" | 回到 **平静 neutral** |

- 点播的表情会在**她说完话后保持 4 秒**，这段时间内她自己的情绪不会覆盖它。
- 如果屏幕处于对话文字模式，点播表情会自动切回角色脸。
- **生气**不会被随机挑中，只有你要求时才出现。

云端情绪与表情的对应：

| 云端情绪 | 表情 |
|---|---|
| happy、laughing、funny、delicious | 开心 |
| sad、crying | 难过 |
| winking、silly、cool | 眨眼 |
| kissy、loving | 嘟嘴 |
| surprised、shocked | 惊讶 |
| angry | 生气 |
| embarrassed | 害羞 |
| thinking、confused | 思考 |
| neutral、relaxed、confident、sleepy | 不改变表情（sleepy 会闭眼） |

## ★★★★★ 2. "这是什么？"：摄像头识物

把东西举到她面前问她。头部的 ESP32‑CAM 拍照、识别，然后告诉你是什么。

| 说 | 结果 |
|---|---|
| "这是什么？" | 识别画面中的主要物体 |
| "看看我手里拿的是什么" | 重点看你手里的东西 |
| "你看到了什么？" / "帮我看看" | 描述眼前的场景 |
| "这个字写的什么？"（任意问题） | 问题会连同照片一起送去识别 |

- 拍照时屏幕会短暂显示**取景画面**，完成后回到角色脸并显示 **已识别**。
- 答案控制在 20 字左右，方便快速说完。
- 图片完全不经过主板：摄像头板自己拍照、上传、识别，只回传一句话。

## ★★★★☆ 3. 头部跟踪：她会跟着你看

三轴头部（俯仰 / 左右 / 侧倾）会转动，让你的脸保持在视野里。

| 方式 | 效果 |
|---|---|
| 说 **"看着我" / "跟着我" / "开启跟踪"** | 开启跟踪 |
| 对摄像头**竖起一根手指** | 开启跟踪（状态栏显示 **跟踪开启**） |
| 说 **"别看我了" / "停止跟踪"** | 关闭跟踪 |

- **每次开机默认关闭**跟踪。
- 做头部动作时、以及任何头部指令后的 4 秒内，跟踪会暂停，避免"向左转头"马上被拉回来。

## ★★★★☆ 4. 语音控制泳池与 SPA

需要 Mac 上运行家庭桥接（见 [§16](#16-mac-上的家庭桥接)）。iAqualink 密码只保存在 Mac 上，不会离开家庭网络；机器人只收到简短的文字摘要。

| 说 | 作用 |
|---|---|
| "泳池状态" / "SPA 好了吗？" | 播报状态，并在屏幕上显示**状态卡片**，直到她说完 |
| "打开过滤泵" / "关掉过滤泵" | `pool_pump` 开/关（过滤泵） |
| "打开 SPA 模式" / "关闭 SPA" | `spa_pump` 开/关（SPA 模式） |
| "打开泳池加热" / "打开 SPA 加热" | `pool_heater` / `spa_heater` |
| "打开泳池灯" / "打开 SPA 灯" | `pool_light` / `spa_light` |
| "打开清洁机" | `cleaner` |
| "泳池温度设到 82 度" | `pool_set`，范围 **70–90 °F** |
| "SPA 温度调到 100 度" | `spa_set`，范围 **80–104 °F** |

- 温度单位为**华氏度**。
- 执行后桥接会重新读取面板状态，最多约 6 秒，确认真的生效。
- 如果她说 **"连接不上家庭网关"**，说明 Mac 睡眠了或桥接没在运行，见 [故障排查](#故障排查)。

## ★★★★☆ 5. 实时摄像头取景

| 说 | 结果 |
|---|---|
| "打开摄像头" / "开启相机" | 全屏显示摄像头实时画面，带科幻风界面：闪烁的 **REC**、状态信息行、角色缩略图 |

## ★★★☆☆ 7. 唤醒词与待机陪伴模式

| 状态 | 表现 |
|---|---|
| **待机**（字幕：*待命中 · 说 "Hi 安可" 唤醒*） | 扬声器静音。仍有"生命感"：每 4.5–9 秒随机变换情绪，每 7–14 秒轻微转动头部 |
| **唤醒** | "Hi 安可"、"安可"、"Hi ENCO"、"你好"、"小智"；定时或摄像头类指令也能直接唤醒 |
| **唤醒中** | 聆听并回答，恢复你设定的音量 |
| **回到待机** | "退下" / "去休息" / "待命"，或 120 秒无对话 |

倒计时或摄像头取景进行中时，她不会进入待机。

## ★★★☆☆ 8. 倒计时与提醒

倒计时在**机器人本地**运行，对话结束后也会继续计时。

| 说 | 结果 |
|---|---|
| "5 分钟后提醒我" / "定个五分钟的闹钟" | 5:00 倒计时 |
| "一个半小时后叫我" | 1:30:00 |
| "一分半倒计时" / "1分30秒" / "90 seconds" | 1:30 |
| "提醒我 10 分钟后喝水" | **带备注**的倒计时：提醒卡片会写"喝水" |
| "还剩多久？" | 剩余秒数 |
| "取消定时器" / "不用提醒了" | 取消 |

- 中文数字可以自然地说：两、二十五、半、一个半、一分半。
- 最长 **24 小时**。
- 计时期间，**T‑MINUS 面板**会占用字幕栏的位置。
- 时间到时：
  - 表情变为惊讶，屏幕显示 **时间到**；
  - 她会被唤醒并播报，如"五分钟时间到"，内容够短时会加上"…提醒我喝水"；
  - 同时弹出提醒卡片。
- 如果时间到时她正在说话，会在 30 秒内反复尝试播报。

## ★★☆☆☆ 11. 字幕栏

底部的胶囊条显示你说的话（**你:**）、她的回复（**Enco:**）和状态提示。

- **单行显示**：文字太长时会以每秒约 3 个字的速度横向循环滚动；短文字居中不动。
- **语音开关**：
  - "打开字幕"：显示；

  - "字幕"：切换。
- **设置断电保存**。倒计时进行时仍会占用该位置。

## ★☆☆☆☆ 15. Wi‑Fi 配网（热点）

没有保存 Wi‑Fi，或者连不上时：

1. 屏幕显示 **【Wi‑Fi 配网模式】** 和一个热点名称。
2. 用手机连接这个热点。
3. 在浏览器打开 **`192.168.4.1`**，选择你的网络（或手动输入 SSID），输入密码。
4. 她会保存、联网，并播放"网络已连接"提示音。

账号密码保存在设备里，重启和刷固件后依然有效。

## ★☆☆☆☆ 16. Mac 上的家庭桥接

`tools/home_bridge/` 是唯一知道 iAqualink 登录信息的程序（存放在 `.env` 中，不会提交到 git）。

| 命令 | 用途 |
|---|---|
| `tools/home_bridge/install_launchd.sh` | 安装为后台服务：登录时自动启动，崩溃后自动重启，并阻止 Mac 闲置睡眠。日志：`~/Library/Logs/enco-home-bridge.log` |
| `python bridge.py discover` | 列出泳池系统中的设备 |
| `python bridge.py status` / `summary` | 打印原始状态 / 机器人实际会收到的文字 |
| `python bridge.py set <设备> on\|off\|set <数值>` | 在终端里测试控制 |
| `python bridge.py serve --host <Mac IP> --port 8787 --allow-control` | 手动启动服务 |

- **安全**：
  - 每个请求都用一次性 nonce 做 HMAC-SHA256 签名；
  - 限速每分钟 20 次；
  - 只接受白名单内的设备和数值范围。
- **供电**：MacBook **用电池并合上盖子时**仍会睡眠。请保持插电并打开盖子，或把桥接迁到树莓派之类常开的设备上。

## ★☆☆☆☆ 17. 角色美术流水线（设计师用）

`python3 tools/face_assets/build_face_assets.py firmware/main` 会把 `tools/face_assets/source/` 里的原图转换成可以写入闪存的 RGB565 贴图。

- 在 2 倍分辨率下处理，每张差分图会自动对齐。
- 边缘先羽化融合，再缩小，保证平滑。
- 发丝飘动帧自动生成。
- 可以为单张贴图单独调整效果，害羞表情的腮红就用了这个。
- 与屏幕像素一致的预览会输出到 `tools/face_assets/build/frame_*.png`。

## 硬件与存储限制

### 板卡

| 部件 | 规格 |
|---|---|
| 主板 | ESP32‑D0WD‑V3（双核 240 MHz），**520 KB SRAM，无 PSRAM**，**4 MB 闪存** |
| 摄像头板 | 安信可 ESP32‑CAM（OV2640，4 MB PSRAM），通过 UART 连接 |
| 屏幕 | 240×320 SPI LCD，RGB565 |
| 头部 | 3 个舵机：俯仰、左右、侧倾 |

### 闪存（4 MB = 4,194,304 字节）

| 分区 | 偏移 | 大小 | 用途 |
|---|---|---|---|
| 引导程序 + 分区表 | 0x0000 | 36 KB | 启动 |
| nvs | 0x9000 | 20 KB（20,480 B） | Wi‑Fi 账号、音量、字幕设置 |
| otadata | 0xE000 | 8 KB | 未使用（为兼容保留） |
| **app0** | 0x10000 | **3,968 KB（4,063,232 B）** | 固件 |
| coredump | 0x3F0000 | 64 KB | 崩溃转储 |

**只有一个应用分区**，所以无法 OTA 空中升级，每次更新都要通过 USB 刷写。

**固件占用（当前版本）：**

| 项目 | 字节 | 占 app0 比例 |
|---|---|---|
| **固件总计** | **3,469,862** | **85.4%** |
| **剩余** | **593,370（约 579 KB）** | 14.6% |
| └ 角色美术（底图 + 33 张贴图） | 595,576 | 14.7% |
| └ 中文字体（普惠 16px）字形位图 | 约 488,000 | 约 12% |
| └ 图标字体（Font Awesome 16/30px） | 约 14,400 | 0.4% |
| └ 提示音（3 个 MP3） | 约 16,200 | 0.4% |
| └ 代码 + 库（Wi‑Fi、TLS、LVGL、Opus、唤醒词……） | 其余（约 2.36 MB） | 约 58% |

链接段：`.flash.text` 1,335,500 B（代码），`.flash.rodata` 2,014,060 B（常量数据，含美术和字体），`.iram0.text` 93,559 B。

**剩余约 579 KB 还能放什么：**

| 新增内容 | 大约占用 | 能否放下 |
|---|---|---|
| 再加一个表情（眼睛 + 嘴巴贴图） | 约 24 KB | ✅ 留出余量后大约还能加 15–20 个 |
| 更多 / 更长的提示音（MP3） | 每个 3–8 KB | ✅ |
| 第二个完整角色（底图 + 全部贴图） | 约 600 KB | ❌ |
| 全屏动画（每帧 150 KB） | 每帧 150 KB | ❌ 超过 2–3 帧就放不下 |

### 内存（520 KB SRAM，无 PSRAM）

静态占用：`.dram0.data` 25,716 B + `.dram0.bss` 51,424 B ≈ 77 KB。

| 时刻 | 可用堆 | 最大连续块 |
|---|---|---|
| 开机、分配音频缓冲前 | 约 215 KB | 约 108 KB |
| 显示 + LVGL 初始化后 | 约 158 KB | 约 108 KB |
| Wi‑Fi 已连接 | 约 88 KB | 约 76 KB |
| **待机** | **约 83 KB** | 约 40–50 KB |
| **聆听 / 说话中** | **约 20–22 KB** | 约 13–17 KB |
| 观测到的最低值 | 约 5–8 KB | — |

**实际影响：**
- **说话时内存最紧张**：她说话时 Wi‑Fi 需要 2,308 字节的连续块，所以所有功能在这个时段都几乎不占内存。
- **角色美术不占内存**：直接从闪存绘制。
- **摄像头必须是独立的板子**：一张 JPEG（25–40 KB）比对话时的剩余内存还大。
- **语音指令列表有固定缓冲**：发给助手的指令列表目前用了 **5,120 字节中的 4,736**。超过后缓冲翻倍，整个会话多占 5 KB 内存，所以新增语音功能需要在别处精简描述。
- **显示任务栈**：8,704 B，峰值时约剩 1.4 KB。

**升级方向**：换成 ESP32‑S3 N16R8（16 MB 闪存、8 MB PSRAM），闪存和内存的限制都会解除。

## 故障排查

| 现象 | 解决办法 |
|---|---|
| "连接不上家庭网关" | Mac 睡眠了或桥接停了。用 `launchctl print gui/$(id -u)/com.enco.homebridge` 查看，并保持 Mac 插电、开盖 |
| 时钟显示 `--:--` | 还没对时（需要联网），Wi‑Fi 连上后稍等几秒 |
| 看不到字幕栏 | 之前关掉了，说"打开字幕" |
| 头不跟随 | 开机默认关闭跟踪，说"看着我"或竖一根手指 |
| 待机时不出声 | 设计如此：待机时扬声器静音，说"Hi 安可" |
| 换了 Wi‑Fi | 等配网热点出现后，重新按 [§15](#15-wi-fi-配网热点) 操作 |
